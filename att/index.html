👥 직원 정보는 직원·권한 관리에서

직원 등록·퇴사(사용 중지)·이름·부서·직위·소속 구분·입사일과 근태 정보(역할·담당 선임·시급·기본 연차·근무시간·출퇴근 기준 시각)는 이제 직원·권한 관리 한 곳에서 관리합니다. 근태 관리에서는 출퇴근·연차·시수·대체시수만 다룹니다.

· 역할 — 선임: 담당 직원(후임)의 시간외 사전신청을 수락하고(수락해야 퇴근 후 보고서 작성 가능), 시수·대체시수를 확인합니다. 휴가·시간외 보고·대체휴무·출장은 즉시 확정 → 출력해서 수기 결재 (직원 쪽 '담당 선임'에 선임 이름을 지정)
· 슬랙 ID — 선임만 입력합니다. 후임이 신청하면 이 슬랙으로 DM이 갑니다. (슬랙 프로필 → ⋮ → 멤버 ID 복사, U로 시작) 봇 토큰은 [기관 설정]에서 한 번만 등록합니다.
· 담당 선임이 비어 있는 직원은 시간외 사전신청을 할 수 없습니다(수락할 사람이 없음). 다른 신청은 됩니다.
· 기본 연차 — 매년 기본으로 주는 연차. 특정 연도만 다르게 주려면 [연차 관리]에서 입력합니다.
· 출근/퇴근 기준 — 모바일 출퇴근 사유 판단용. 비우면 [기관 설정]의 기본 시각이 적용됩니다. 단축근무자는 퇴근 기준을 따로 입력하세요(예: 16:00).
· 주간 근무시간 — 단축근무자만 입력(예: 30). 비워 두면 기본 40시간으로 시간외 수당을 계산합니다.

📍 출퇴근 · 근무지 설정 (모바일 출퇴근 기록)
직원이 모바일에서 출퇴근을 찍으면 근무지에서 허용 반경 안인지, 기준 시각에 맞는지 확인하고 벗어나면 사유를 받습니다. 주소 변환(좌표→주소)과 주소 검색에는 카카오 REST API 키가 필요합니다. ✅ 도협회가 등록한 공용 키를 사용 중이라 지회에서 키를 넣을 필요가 없습니다. 근무지 주소만 입력하세요.
① developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가하기(이름 자유)
② 앱 → 앱 키에서 REST API 키 복사 → 아래에 붙여넣고 저장 / 그리고 앱의 제품 설정 → 카카오맵 → 사용 설정 ON (꺼져 있으면 주소 변환이 거부됩니다)

③ 근무지 주소를 입력 → 주소로 좌표 찾기 (또는 근무지에서 현재 위치로) → 저장
🔒 회색으로 잠긴 항목은 도협회 공통 설정이라 지회에서 바꿀 수 없습니다.
PC는 GPS가 없어 위치가 부정확합니다. 사무실 인터넷(공유기·와이파이)으로 접속해 출퇴근하면 위치와 상관없이 근무지 안으로 기록됩니다. 사무실 PC에서 [지금 이 PC 주소 넣기] → 저장하세요. 인터넷 회사가 주소를 바꾸면 다시 넣어야 합니다.
이 거리 안이면 사유 없이 기록 (기본 300m)
직원별 기준은 [직원 관리]에서 따로 지정 (단축근무 등)
🔔 슬랙 알림 (후임이 신청하면 선임에게 DM)
🏛 도협회에서 봇 토큰을 한 번 저장하면 모든 지회에 같이 적용됩니다. 지회는 따로 넣지 않아도 됩니다. (지회가 직접 넣으면 그 지회 토큰을 씁니다)
휴가 · 시간외(사전신청·보고서) · 대체휴무 · 시수 · 대체시수를 후임이 신청/보고하면, 그 직원의 담당 선임 슬랙 DM으로 알려 줍니다.
① api.slack.com/apps → Create New App → From scratch (우리 슬랙 워크스페이스 선택)
② OAuth & Permissions → Bot Token Scopes에 chat:write, im:write 추가 → Install to Workspace → Bot User OAuth Token(xoxb-…) 복사
③ 아래에 붙여넣고 저장 → [직원 관리]에서 선임의 슬랙 ID(프로필 → ⋮ → 멤버 ID 복사) 입력·저장 → 테스트
📣 전 직원 슬랙 알림 확인 (도협회 전용)
슬랙 ID가 들어간 직원에게 확인 메시지를 보내고, 사람마다 잘 갔는지 결과를 보여 줍니다. 받는 사람이 많으니 근무 시간에 보내 주세요. (지회마다 차례로 보내서 1~2분 걸립니다)
📋 결재라인 (전체 신청서 공통)
휴가·시간외·시수·대체휴무·대체시수 — 모든 신청서를 인쇄할 때 결재란과 수신처(OOO 귀하)에 공통으로 들어갑니다. 직원의 부서명과 같은 줄이 적용되고, 없으면 첫 줄이 적용됩니다.
